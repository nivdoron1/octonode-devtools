Write one project-relative file using its exact base revision.

## When and how to call

- Effect: **write**.
- Scope: workspace plus selected project. Pass `projectId` explicitly for a multi-project connection; otherwise the connection default applies.
- Backend request: `PUT /api/projects/{projectId}/files/content`. The MCP server fills the URL path, query, and body from the flat arguments below; do not send an HTTP request yourself.
- Result: the upstream response in `data`. Check MCP `isError` and JSON `ok`.
- Before calling: Read the file first with `project_file_read`; use its exact revision as `baseRevision`. Reconcile conflicts by rereading.
