## When and how to call

- Scope: workspace plus selected project. Pass `projectId` explicitly for a multi-project connection; otherwise the connection default applies.
- Backend request: `PUT /api/nodes/{nodeId}/source/signature`. The MCP server fills the URL path, query, and body from the flat arguments below; do not send an HTTP request yourself.
- Result: the upstream response in `data`. Check MCP `isError` and JSON `ok`.
- Before calling: Read the node source first. Its revision guards the signature change; validate the project afterward.
