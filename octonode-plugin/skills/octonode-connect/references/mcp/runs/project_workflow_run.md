Run one workflow and return its bounded event stream.

## When and how to call

- Effect: **write**.
- Scope: workspace plus selected project. Pass `projectId` explicitly for a multi-project connection; otherwise the connection default applies.
- Backend request: `POST /api/workflows/{workflowId}/run`. The MCP server fills the URL path, query, and body from the flat arguments below; do not send an HTTP request yourself.
- Result: bounded events in `data.events`. Check MCP `isError` and JSON `ok`.
- Before calling: Workflow runs may have side effects. Inspect returned events and the persisted run before reporting success.
