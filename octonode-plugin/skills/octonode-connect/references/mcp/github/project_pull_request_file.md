Read a PR file's base/head source and changed lines inside the authorized project. Check headSha against the PR before reviewing; never publish a review without user approval.

## When and how to call

- Effect: **read**.
- Scope: workspace plus selected project. Pass `projectId` explicitly for a multi-project connection; otherwise the connection default applies.
- Backend request: `GET /api/architectures/{architectureId}/github/pull-requests/{number}/review-file`. The MCP server fills the URL path, query, and body from the flat arguments below; do not send an HTTP request yourself.
- Result: the upstream response in `data`. Check MCP `isError` and JSON `ok`.
- Before calling: Read `project_pull_request` and confirm its current head SHA before reviewing the file. The hosted tools do not publish reviews.
