Save workflow topology using the exact graph revision.

## When and how to call

- Effect: **write**.
- Scope: workspace plus selected project. Pass `projectId` explicitly for a multi-project connection; otherwise the connection default applies.
- Backend request: `POST /api/workflows/{workflowId}/topology`. The MCP server fills the URL path, query, and body from the flat arguments below; do not send an HTTP request yourself.
- Result: the upstream response in `data`. Check MCP `isError` and JSON `ok`.
- Before calling: Read `project_workflow_graph` first, preserve topology you do not intend to change, validate proposed edges, and use its exact graph revision.
